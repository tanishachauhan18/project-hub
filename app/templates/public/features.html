Complete Feature Matrix

Comprehensive Features for University Projects

A deep dive into the modules powering ProjectHub.

Registration & Approval Gate

Prevents unverified account creation. Administrators review and approve student roll numbers and departments before access is granted.

Team Formation (2–4 Members)

Student leaders can assemble teams with custom member role titles such as Frontend Engineer, Backend Developer, or ML Researcher.

Faculty Guide Selection

Students submit proposals directly to certified faculty members who can accept or reject requests based on domain expertise and capacity.

Dynamic Progress Calculation

Progress bar percentages automatically calculate based on the completed weights of configured milestones (SRS, Design, Modules, Viva).

Source Code Collaboration

Built-in code repository with syntax highlighting, commit messages, author tagging, and external GitHub repository linking.

Rubric Evaluation Sheet

Standardized 5-criteria grading rubric (/20 each, Total /100) covering Presentation, Code Quality, Documentation, Viva, and Innovation.
